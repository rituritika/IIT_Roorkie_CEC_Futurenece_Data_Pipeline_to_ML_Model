Mini-project for lead qualification using a defined rubric, data validation, and AI-assisted analysis.
# Lead Intelligence System

## Project Overview
A Python-based lead qualification tool that validates lead data, scores leads using a transparent qualification rubric, assigns outreach priorities, and generates personalized outreach messages using the Groq LLM API.

## Features
- CSV input for lead data
- Qualification scoring based on five factors
- Lead classification and priority assignment
- Missing-field tracking and reasoning for decisions
- LLM-assisted outreach message generation
- Batch processing for large datasets
- Retry handling and local reasoning fallback when API requests fail
- JSON report generation

## Technology Stack
- Python
- Groq API (`openai/gpt-oss-20b`)
- CSV and JSON
- Requests library

## Prerequisites
- Python 3.10 or later
- A Groq API key for LLM functionality

## Setup
Install dependencies:

```bash
pip install -r requirements.txt
```

Set the API key in your terminal. Do not share or commit your API key.

```bash
export GROQ_API_KEY="your_groq_api_key"
```

## Run the Project
Run the pipeline using the supplied 100-lead dataset:

```bash
python main.py leads_full_scale_100.csv
```

You can also supply another input CSV:

```bash
python main.py leads_testing.csv
```

The generated report is saved as `output_report.json` by default.

## Lead Qualification Methodology

Each lead is evaluated using five factors:

1. Company Size – Maximum 2 points
2. Industry Fit – Maximum 2 points
3. Lead Source – Maximum 2 points
4. Interaction Freshness – Maximum 2 points
5. Data Completeness – Maximum 2 points

Maximum Score: 10

### Qualification Criteria
- 7–10: QUALIFIED
- 4–6: REVIEW
- 0–3: REJECTED
- Missing critical information: REVIEW

### Priority Classification
- HIGH: Qualified leads with score >= 8
- MEDIUM: Qualified or Review leads
- LOW: Remaining leads

Every lead receives a score and an explanation
to support transparent decision-making.

## Output
The JSON report includes:
- Total leads processed
- Qualified, review, and rejected counts
- Qualification scores and reasoning
- Missing fields
- Priority queue
- Outreach messages for qualified leads

## Sample Run
The 100-lead test run processed all 100 leads and produced a JSON report. Results from the current run included 59 qualified leads and 41 review leads. These results depend on the input dataset and scoring rules.

## Error Handling
The application retries certain API failures and falls back to local reasoning when LLM requests fail. LLM availability and rate limits may affect whether outreach messages are generated by the API or fallback logic.
